# Customer Segmentation using K-Means Clustering

## Overview
This project applies the K-Means Clustering algorithm to segment customers based on their Annual Income and Spending Score. The objective is to identify distinct customer groups and gain insights into customer behavior for better business decision-making.

## Project Workflow
- Data Loading and Preprocessing
- Feature Selection
- Data Scaling
- Elbow Method for Optimal Clusters
- K-Means Clustering
- Customer Segmentation Visualization

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-Learn

## Results
The model successfully grouped customers into different segments based on spending patterns and income levels. These segments can help businesses understand customer preferences and design more effective marketing strategies.

## Output
- Elbow Method Graph
- Customer Segmentation Plot
- Cluster Centers Visualization

## Conclusion
K-Means Clustering proved effective in identifying meaningful customer groups, providing valuable insights that can support data-driven business decisions and customer-focused strategies.
